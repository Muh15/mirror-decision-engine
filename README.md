# MIRROR — Decision Simulation Engine

**جرّب القرار على نسخة افتراضية من الواقع قبل تنفيذه.**

MIRROR هو نموذج أولي لمحرك محاكاة قرارات يساعد الجهات التشغيلية على اختبار السيناريوهات ومقارنة أثرها قبل تنفيذ القرار على أرض الواقع.

## النسخة الحالية

الـDemo يركز على 3 مجالات:

- الطرق والنقل
- المطارات
- الفعاليات والحشود

### دورة القرار

**قرار → محاكاة → قياس الأثر → مقارنة البدائل → توصية**

## تشغيل المشروع

المشروع عبارة عن صفحة ويب مستقلة ولا يحتاج إلى Backend أو تثبيت حزم.

افتح `index.html` في المتصفح، أو انشر المستودع عبر GitHub Pages للحصول على رابط مباشر للعرض.

## ملاحظة مهمة

الأرقام والنتائج الموجودة في هذه النسخة **بيانات محاكاة توضيحية للـDemo فقط**، وليست نتائج تشغيلية أو تنبؤات حقيقية لمدينة أو مطار محدد.

## الرؤية

الهدف طويل المدى هو بناء **Decision Simulation Platform** يمكنه محاكاة القرارات المعقدة في النقل والبنية التحتية والتشغيل والطوارئ، ثم تقديم مقارنة قابلة للفهم لصاحب القرار قبل التنفيذ.
